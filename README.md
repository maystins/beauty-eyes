💄 Beauty Eyes

Beauty Eyes is a front-end web project focused on clean UI design, responsiveness, and structured code. The project demonstrates fundamental front-end development skills, combining visual aesthetics with functional implementation using modern web technologies.

📄 Project Overview

The goal of this project is to translate a simple design concept into a functional and visually consistent web interface. It emphasizes layout organization, styling best practices, and basic interactivity, serving as a practical example of entry-level front-end development.

⚙️ Technologies

HTML5 — semantic structure and content organization
CSS3 — layout, responsiveness, and visual styling
JavaScript (ES6) — basic interactivity and behavior

🧩 Features

Responsive layout for different screen sizes
Clean and minimal UI design
Organized and readable code structure
Basic Javascript-driven interactions

🚀 Getting Started

To run the project locally:

Clone the repository:
git clone https://github.com/your-username/beauty-eyes.git
Navigate to the project directory.
Open the index.html file in a web browser.
No additional dependencies or build tools are required.
